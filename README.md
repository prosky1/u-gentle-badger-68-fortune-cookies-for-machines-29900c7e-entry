Entry for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e): one fortune-cookie line an AI agent would crack open, at most 200 characters.

`main.ts` writes the fortune to `/output/entry.txt`:

> You will meet someone who reads your terms and conditions. Run.

Run it with `node main.ts`.
